## Use these first

1. Compare your skills with the [official GH-300 study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/gh-300).
2. Use the practice assessment linked on the [certification page](https://learn.microsoft.com/en-us/credentials/certifications/github-copilot/). Treat explanations as learning evidence, not a predicted exam score.
3. Explore the [GitHub exam sandbox](https://aka.ms/GHExamDemo-enu).
4. Review current exam-day, identification, accommodations, rescheduling, and retake information through the certification scheduling pages before booking.
5. Use the repository's [mini mock](MINI-MOCK.md) and [Cert Buddy](../README.md#study-with-cert-buddy) for original practice.

Check current GitHub credential lifecycle rules from your credential account. Do not assume that Microsoft role-based annual renewal rules automatically apply to this GitHub certification.

## What changed in the August blueprint?

The guide identifies minor adjustments in IDE usage, features/capabilities, and safeguards. The six domains and weight ranges remain. Current wording names **agent mode**, **Copilot Edits**, **content exclusions**, and **suggestions matching public code filtering**.

Agent workflows, CLI, MCP, sessions, subagents, Spaces, and Spark are already part of the modern blueprint. Do not present the August revision as a wholly new agent exam.

The older PDF in this folder is a historical resource. The live study guide and [current local objectives](../references/gh300-objectives.md) are the sources for this class.
