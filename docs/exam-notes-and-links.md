# GH-300 exam notes and official links

**Checked September 23, 2026.** The full booking, practice, and credential link set is in [the resource links](GH-300-RESOURCE-LINKS.md#register-schedule-and-sit-the-exam).

| Item | Current guidance |
|---|---|
| Exam | GH-300: GitHub Copilot |
| Skills measured | Effective **August 7, 2026** |
| Exam time | **100 minutes** |
| Delivery partner | **Pearson VUE**, exclusively, since July 1, 2025, in partnership with Microsoft Learn |
| Testing options | A Pearson VUE test center **or** an online proctored seat |
| Languages | English, Portuguese, Spanish, Korean, Japanese |
| Scheduling window | No more than **90 days** in advance |
| Identification | An unexpired government-issued photo ID whose name matches your registration exactly. Failing to present one counts as a missed appointment with no refund |
| Passing score | **700** on the scaled score; do not interpret this as 70% correct |
| Credential validity | **24 months**; see the renewal note below |
| Price | Region-dependent; check the scheduling page |
| Question format | Use the official sandbox to practice interactions; do not assume a fixed question count |
| Account | Microsoft recommends a personal Microsoft account for durable access to certification records |

**Renewal is in transition.** GitHub is moving to Microsoft's recertification process. Certifications expiring before that process is available are being extended by six months, and GitHub has published a contact route for holders whose credential already lapsed. Check your own credential record rather than assuming the Microsoft role-based annual renewal rule applies here.

## Use these first

1. Compare your skills with the [official GH-300 study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/gh-300).
2. Take the [free official GH-300 practice assessment](https://learn.microsoft.com/en-us/credentials/certifications/github-copilot/practice/assessment?assessment-type=practice&assessmentId=218035372&practice-assessment-type=certification). It is written by the team that builds the exam, gives a rationale on every question, and can be repeated. Treat the score as evidence about weak domains, not as a predicted exam result.
3. Explore the [GitHub exam sandbox](https://GHCertDemo.starttest.com) so the interface is familiar before exam day.
4. Review exam-day, identification, [accommodations](https://learn.microsoft.com/en-us/credentials/certifications/request-accommodations), rescheduling, and retake information through the [exam policies](https://learn.microsoft.com/en-us/credentials/certifications/certification-exam-policies) before booking.
5. Use the repository's [60-item practice bank](practice/README.md), [mini mock](MINI-MOCK.md), and [Cert Buddy](../README.md#study-with-cert-buddy) for original practice.

Check current GitHub credential lifecycle rules from your credential account. Do not assume that Microsoft role-based annual renewal rules automatically apply to this GitHub certification.

## What changed in the August blueprint?

The guide identifies minor adjustments in IDE usage, features/capabilities, and safeguards. The six domains and weight ranges remain. Current wording names **agent mode**, **Copilot Edits**, **content exclusions**, and **suggestions matching public code filtering**.

Agent workflows, CLI, MCP, sessions, subagents, Spaces, and Spark are already part of the modern blueprint. Do not present the August revision as a wholly new agent exam.

The live study guide and [current local objectives](../references/gh300-objectives.md) are the sources for this class. Superseded exam materials are available in Git history; they are not the current exam baseline.
