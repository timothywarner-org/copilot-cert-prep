# GitHub Feature Update Summary – July 2025

## GitHub Copilot

| Update | Description |
|--------|-------------|
| Agentic coding agent (Public preview → GA in more SKUs) | [Copilot’s coding agent now supports Copilot Business](https://github.blog/changelog/2025-06-24-github-copilot-coding-agent-is-now-available-for-copilot-business-users/). Assign an issue to Copilot and it spins up a secure Actions environment, plans work, runs tests, and submits a PR. |
| Agent mode GA with MCP tools | [Visual Studio 17.14 update](https://github.blog/changelog/2025-06-17-visual-studio-17-14-june-release/) supports MCP, new models, usage tracking, and Output Window context. |
| Coding vs Agent mode | [Clarified in GitHub blog](https://github.blog/developer-skills/github/less-todo-more-done-the-difference-between-coding-agent-and-agent-mode-in-github-copilot/) — agent mode is IDE-based, coding agent runs in GitHub Actions. |
| .instructions.md support | [New instructions file support](https://github.blog/changelog/2025-07-23-github-copilot-coding-agent-now-supports-instructions-md-custom-instructions/) under `.github/instructions` with YAML front-matter. |
| Select base branch for agent tasks | [You can now set base branch](https://github.blog/changelog/2025-07-23-agents-page-set-the-base-branch-for-github-copilot-coding-agent-tasks/) for Copilot-generated PRs. |
| Improved attachments and context | [Copilot Chat enhancements](https://github.blog/changelog/2025-07-09-new-copilot-chat-features-now-generally-available-on-github/): rich previews, file uploads, image support. |
| @mention support | [Attach issues and files](https://github.blog/changelog/2025-06-03-copilot-chat-now-supports-attaching-references-using-the-symbol/) in chat via @. |
| Remote GitHub MCP server | [Public preview](https://github.blog/changelog/2025-06-12-remote-github-mcp-server-is-now-available-for-public-preview/) eliminates local setup; connect MCP server via UI. |
| Copilot Spark | [Natural language to app pipeline](https://github.blog/changelog/2025-07-23-github-spark-in-public-preview-for-copilot-pro-subscribers/) via Spark, for Pro+ plans. |

## GitHub Advanced Security (GHAS)

| Update | Description |
|--------|-------------|
| Product unbundling | [GHAS now split](https://resources.github.com/evolving-github-advanced-security/) into Code Security and Secret Protection with distinct pricing. |
| Secret scanning – validity checks | [Over 40 new detectors](https://github.blog/changelog/2025-07-22-secret-scanning-adds-validity-checks-for-over-40-secret-detectors/) with active/inactive status check. |
| Push protection config | [Customizable scanning patterns](https://github.blog/changelog/2025-06-25-configuring-which-secret-scanning-patterns-are-included-in-push-protection-is-in-public-preview/). |
| Delegated dismissals | [Apps and security teams](https://github.blog/changelog/2025-07-01-delegated-alert-dismissal-for-code-scanning-is-now-generally-available/) can review dismissal requests. |
| Copilot Autofix | [CodeQL + AI](https://github.blog/news-insights/product-news/secure-code-more-than-three-times-faster-with-copilot-autofix/) auto-fixes common security issues with PRs. |
| CodeQL build-free scanning | [C/C++ repos](https://github.blog/changelog/2025-06-03-codeql-can-be-enabled-at-scale-on-c-c-repositories-in-public-preview-using-build-free-scanning/) can be analyzed without compiling. |
| Rust support | [Rust scanning](https://github.blog/changelog/2025-06-30-codeql-support-for-rust-now-in-public-preview/) in CodeQL now in public preview. |
