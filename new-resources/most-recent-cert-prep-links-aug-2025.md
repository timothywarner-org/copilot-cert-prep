## Exam Domains and Weighting

The GitHub Copilot certification exam (GH-300) covers seven domains with the following weight distribution:

### Domain 1: Responsible AI (7%)
- Understanding ethical AI principles
- Identifying AI risks and limitations
- Mitigating potential harms
- Validating AI outputs

### Domain 2: GitHub Copilot Plans and Features (31%)
- Copilot Individual, Business, and Enterprise plans
- IDE inetegration features
- Chat functionality
- Organization management

### Domain 3: How GitHub Copilot Works and Handles Data (15%)
- Data pipeline lifecycle
- Context gathering and processing
- Large language model interactions
- Data flow and privacy considerations

### Domain 4: Prompt Crafting and Prompt Engineering (9%)
- Effective prompt design
- Zero-shot vs few-shot prompting
- Best practices for prompt engineering
- Context optimization techniques

### Domain 5: Developer Use Cases for AI (14%)
- Productivity improvements
- Code generation and refactoring
- Documentation assistance
- Legacy code modernization
- Debugging support

### Domain 6: Testing with GitHub Copilot (9%)
- Unit test generation
- Integration test creation
- Edge case identification
- Test quality improvement

### Domain 7: Privacy Fundamentals and Context Exclusions (15%)
- Content exclusion configuration
- Privacy protection measures
- Security best practices
- Data handling compliance
